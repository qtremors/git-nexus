# GitNexus

Native GitHub and Git tools built with Rust and GPUI.

Version 0.2.2.

## Development

Application code and local build tools live in `git-nexus-app/`. Product documents, branding and the website live at the repository root.

```sh
cd git-nexus-app
cargo build --workspace --locked -j 2
```
