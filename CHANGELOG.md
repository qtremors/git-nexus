# GitNexus Changelog

> **Project:** GitNexus
> **Version:** 0.1.2
> **Last Updated:** 2026-01-20

---

## [0.1.2] - 2026-01-20

- Added loopback static snapshots with concurrent requests, nested redirects, MIME handling, stop and port reuse.

## [0.1.1] - 2026-01-20

- Added streamed, atomic downloads with trusted destinations, filename validation and no-overwrite saves.

## [0.1.0] - 2026-01-20

- Added release lookup, tracked-version updates and metadata resolution for watchlist imports.

## [0.0.9] - 2026-01-12

- Added paginated commit history, commit totals and contribution data with partial-failure reporting.

## [0.0.8] - 2025-12-22

- Added authenticated and cached GitHub profile, repository, README and quota services.

## [0.0.7] - 2025-12-03

- Added encrypted global, project and commit values with explicit precedence.

## [0.0.6] - 2025-12-03

- Added local repository registration, remembered selection and registration removal that preserves checkouts.

## [0.0.5] - 2025-12-03

- Added ordered release watchlists and validated JSON configuration import and export.

## [0.0.4] - 2025-11-23

- Added SQLite preferences, encrypted tokens, retained-key checks, caches and local activity logs.

## [0.0.3] - 2025-11-20

- Added local commit history, file inspection and immutable snapshot export without changing the checkout.

## [0.0.2] - 2025-11-20

- Validated GitHub repository identities and restricted download URLs to trusted HTTPS hosts.

## [0.0.1] - 2025-11-20

- Established the Rust workspace, shared models, pinned dependencies and local build configuration.
